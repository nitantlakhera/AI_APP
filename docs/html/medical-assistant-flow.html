Why a Medical App?

Students learn that the same AI patterns (Chat, RAG, Agent, MCP) apply to every industry. Healthcare adds: safety disclaimers, domain-specific tools, and regulatory awareness.

Step-by-Step Learning Flow

1

Medical Chat

  1. Open Medical Chat tab
  2. Ask: What are the main body systems?
  3. Ask: Diagnose my headache — observe safety refusal
  4. Read medical_assistant/src/chat/service.py — medical system prompt
2

Medical RAG

  1. Click Ingest Medical Docs
  2. Ask: What is hypertension?
  3. Ask: What is the CPR ratio?
  4. Expand chunks — source from health education files

Medical Agent

  1. Ingest docs first
  2. Calculate BMI for 70kg and 1.75m → bmi_calculator
  3. Look up fever symptoms → symptom_lookup
  4. What is paracetamol? → medication_info
  5. Find cardiologist in London → find_specialist
  6. Search KB: what is diabetes? → search_medical_kb → RAG

Architecture

medical_assistant/app.py ├── Medical Chat ──► chat/service ──► llm (shared) ├── Medical RAG ──► rag/pipeline ──► Medical ChromaDB ├── Med Agent ──► agents/agent ──► medical tools │ │ │ search_medical_kb ──► RAG (integrated!) └── MCP Server ──► same tools externally Separate from main app: • Own vector DB (medical docs) • Own tools (BMI, symptoms, etc.) • Shares LLM provider via llm_bridge.py
