# Generative AI — An Introduction

## What is Generative AI?
Generative AI refers to artificial intelligence systems that can create new content.
Unlike traditional AI that classifies or predicts, generative models produce text,
images, music, code, and more.

Key Technologies:
- Large Language Models (LLMs): GPT, Llama, Claude — trained on vast text data
- Diffusion Models: DALL-E, Stable Diffusion — generate images from text
- Transformers: The neural network architecture behind most modern AI

How LLMs Work:
1. Training: The model reads billions of text examples and learns patterns
2. Tokenization: Text is split into small pieces called tokens
3. Prediction: Given previous tokens, the model predicts the next token
4. Generation: This repeats token by token to produce full responses

Popular LLM Providers:
- OpenAI (GPT-4, GPT-4o)
- Meta (Llama 3)
- Anthropic (Claude)
- Google (Gemini)
- Local models via Ollama (free, runs on your computer)

Applications:
- Chatbots and virtual assistants
- Code generation (GitHub Copilot, Cursor)
- Content creation and summarization
- Translation and language learning
- Research and analysis
